# START_REACT_FOUNDATION_008

## Enterprise React Patterns (Q61–Q70)

### Q61. Higher-Order Components (HOC)
A function that takes a component and returns an enhanced component.

### Q62. Render Props
Share logic by passing a render function.

### Q63. Compound Components
Create expressive APIs like Tabs, Accordion, Menu.

### Q64. Custom Hooks
Extract reusable stateful logic.

### Q65. Provider Pattern
Share application-wide services using Context Providers.

### Q66. Context Architecture
Split contexts to minimize unnecessary re-renders.

### Q67. Dependency Injection
Inject API and service layers for easier testing.

### Q68. SOLID in React
Apply SRP, OCP, DIP and composition to component design.

### Q69. Feature Folder Structure
Organize code by feature instead of file type.

### Q70. Enterprise Architecture
Layers: UI, Features, Services, API, State, Routing, Shared Components.
