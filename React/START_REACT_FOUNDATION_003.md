# START_REACT_FOUNDATION_003

## Questions 16-20

### Q16. What is React Fiber?
Fiber is React’s rendering engine that enables scheduling, prioritization, and interruptible rendering.

### Q17. Render vs Commit phase
Render calculates changes; Commit applies them to the DOM.

### Q18. What causes re-renders?
State changes, prop changes, context updates, and parent renders.

### Q19. How to avoid unnecessary re-renders?
React.memo, useMemo, useCallback, stable props.

### Q20. Common interview tips
Explain concepts with diagrams, mention performance trade-offs, and discuss real-world examples.
