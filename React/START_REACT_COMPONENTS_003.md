### Q31. Component Lifecycle

### Q32. Render Phase

### Q36. Error Boundaries

Render computes changes; Commit updates the browser DOM.

### Q38. Re-render Triggers
State, props, context, and parent renders.

### Q39. Avoiding Re-renders
React.memo, useMemo, useCallback, stable props.

### Q40. Keys
Use stable unique keys in lists.

### Q41. Conditional Rendering
if, ternary, &&, early return.

### Q42. Fragments
Group elements without extra DOM nodes.

### Q43. Portals

### Q44. Suspense
