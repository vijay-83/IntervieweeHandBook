# START_REACT_FOUNDATION_002

## Questions 11-15

### Q11. What is reconciliation?
React compares previous and current Virtual DOM trees and updates only changed nodes.

### Q12. Why are keys important?
Keys uniquely identify list items and help React efficiently reconcile changes.

### Q13. What are Synthetic Events?
A cross-browser wrapper around native browser events.

### Q14. Conditional rendering
Use if, ternary, &&, or switch to render UI based on conditions.

### Q15. Rendering flow
State/Props change -> Render -> Diff -> Commit.
