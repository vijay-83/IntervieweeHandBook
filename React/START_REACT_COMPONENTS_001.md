## Part 001 – JSX Fundamentals (Q1–Q15)

### Q1. What is JSX?
JSX is a syntax extension for JavaScript that allows HTML-like markup in React.

### Q2. Why JSX?
Readable, reusable, expressive UI.

### Q3. Is JSX mandatory?
No. React can use React.createElement() directly.

### Q4. JSX Compilation
JSX -> Babel -> JavaScript -> Browser.

### Q5. JSX vs HTML
- className
- htmlFor
- camelCase events
- self-closing tags

### Q6. JavaScript Expressions
Use {} to embed expressions.

### Q7. Conditional Rendering
if, ternary, &&.

### Q8. Rendering Lists
Use map() with unique keys.

### Q9. React Fragments
Avoid unnecessary DOM elements.

### Q10. JSX Attributes
Pass strings, objects, booleans and handlers.

### Q11. Spread Props
<Component {...props} />

### Q12. Inline Styles
Use JavaScript objects.

### Q13. Escaping
React escapes rendered values by default.

### Q14. Common Mistakes
Missing keys, wrong attribute names.

### Q15. Interview Tips
Understand Babel transformation and Virtual DOM.
