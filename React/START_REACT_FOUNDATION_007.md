## React Advanced Foundation (Q51–Q60)

### Q51. React Rendering Pipeline
User Action → State/Props Change → Scheduler → Render → Reconciliation → Commit → Paint.

### Q52. React Fiber
Fiber is React's rendering engine that enables prioritization and interruptible rendering.

### Q53. Reconciliation
React compares old and new Virtual DOM trees and updates only changed nodes.

### Q54. Batching
Multiple state updates are grouped into a single render.

### Q55. Concurrent Rendering
Allows React to prioritize urgent UI updates.

### Q56. React.memo
Memoizes a component to avoid unnecessary renders.

### Q57. forwardRef
Allows a parent to access a child's DOM ref.

### Q58. useImperativeHandle
Exposes selected methods through a ref.

### Q59. Composition vs Inheritance
React recommends composition for flexibility and reuse.

### Q60. Performance Tips
Use stable keys, profile before optimizing, memoize only when needed.
